# Publication boundary

This is a deliberately small sanitized export, not a dump of the research directory.
The original private workspace and its frozen artifacts were not moved, committed
or altered by publication. The803-file census names private sources; their text,
instruction listings, arrays and binaries are not published by this repository.

## Included

- Independently authored technical explanation, addresses, object relationships,
  bounded pseudocode and explicit confidence/verification distinctions.
- Artifact and expected-original-range SHA-256 metadata, not the bytes hashed.
- A source-level DSP API with no firmware offsets or native installation address.
- A small independently authored read-only stock-metadata checker.
- Links/commit pins to community projects; no vendored third-party implementation.

## Excluded

- Stock or modified .syx files, extracted sections and complete binaries.
- Full disassembly, opcode/hex blobs, full binary diffs and target objects/libraries.
- Firmware-derived waveform/coefficient tables, graphics/fonts and generated DSP packages.
- Private audit libraries, original report contents and generated audio.
- Account credentials, private email addresses and absolute local filesystem paths.

The source catalog is a **locator and hash registry**, not publicly inspectable proof
of the omitted contents. Reproduction must use a contributor's own legitimate stock
firmware and independently reviewed implementation. Historical source headings can
be superseded; indexing a report does not adopt its old claims.

MIT covers only independent materials actually included here. It does not grant
rights in Elektron firmware or assets. Cited SyntHack/FM4 implementations retain
their own licensing; copying them later requires retaining their notices.

No firmware updater, automatic deployment, hardware command, flashing instructions
or upstream issue submission is performed here. Check every future staged file
and commit tree; .gitignore is a convenience, not a substitute for review.
