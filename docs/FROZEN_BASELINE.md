# Private frozen baseline — provenance only

The private milestone is **MACHINE45 V2 BRANCHLESS OFFLINE BASELINE: FROZEN**.
The full baseline and all original firmware remain outside this repository.
Names, sizes and SHA-256 values are in [ARTIFACT_HASHES.json](../metadata/ARTIFACT_HASHES.json);
they are identifiers, not download links or an approval to flash.

- Full offline research candidate exists; composed device path strongly supported.
- No local whole-device emulator run or hardware validation was recovered.
- Sound current-Kit byte persistence is locally qualified; Pattern and standalone
  Sound application are unproven.
- MAIN page-accessor CCR.X is resolved safe for the recovered caller set.
- Static performance work is exhausted; absolute deadline blocked; relative render
  cost comparable but unproven; hardware timing untested.
- The generic DSP API/offline SDK design exists; native installation is unavailable.

The private candidate includes an optional V2 waveform test kernel. It is not a
required design for a new Machine, not a released synth and not included here.
A donor-only registration experiment can precede custom native DSP installation.
Future work must use a new source-controlled implementation, not overwrite the
private frozen artifacts or treat their prior READY labels as hardware approval.
